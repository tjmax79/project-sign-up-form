
# 📋 Sign-up Form Project

## 📖 Overview
This project is a simple **sign-up form** built with **HTML and CSS**.  
It demonstrates form styling, custom fonts, responsive layout, and interactive effects like zoom-in/zoom-out scaling when the form container is clicked.

The goal is to practice front-end fundamentals while creating a clean, user-friendly interface.

---

## ✨ Features
- **Custom Font Integration**: Uses the `@font-face` rule to load the *Norse* font.
- **Responsive Background**: Full-page background image with `cover` and `center` positioning.
- **Form Styling**:
  - Labels and inputs styled with borders, focus states, and required field indicators.
  - Password fields marked as required with red borders.
- **Interactive Container**:
  - Zoom-in/zoom-out effect using pure CSS (checkbox hack or focus-within).
  - Smooth transitions with `transform` and `transition`.
- **Buttons & Layout**:
  - Styled submit button with hover/focus effects.
  - Flexbox used for form field alignment.
- **Logo Section**:
  - Positioned logo and title styled with custom font.

---

## 🛠️ Technologies Used
- **HTML5** for structure  
- **CSS3** for styling and animations  
- **Flexbox** for layout  
- **Custom Fonts** via `@font-face`

---

## 🚀 How to Run
1. Clone or download this repository.
2. Place the project files in a local folder.
3. Ensure the font file (`Norse-Bold.otf`) and background image (`unsplash.jpg`) are in the correct paths.
4. Open `index.html` in your browser.
